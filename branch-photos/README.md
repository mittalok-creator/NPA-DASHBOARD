# Branch geo-tagged photos

Drop the 57 branch geo-tagged photos here (GitHub web UI: **Add file → Upload files**,
on this same branch).

Name each file by SOL ID so it can be matched to the right branch, e.g.:

```
9269.jpg          (R O Hathras)
9306.jpg          (Adarshnagar)
9270.jpg          (Agsauli)
```

`SOLID_BranchName.jpg` (e.g. `9269_ROHathras.jpg`) also works.

This folder is a temporary staging area for extracting exact GPS coordinates
(from each photo's EXIF data) into the branch map — it is not app-facing data
and can be cleaned up once the coordinates are extracted.
